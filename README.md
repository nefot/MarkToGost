# MarkToGost

Конвертер Markdown → DOCX для учебных и деловых документов: курсовых, ВКР, отчётов по практике,
рефератов, договоров. Текст пишется в обычном редакторе, а оформление по ГОСТ 7.32, титульный
лист, содержание и нумерацию делает MarkToGost.

Что умеет:

- **типы документов** с готовым оформлением, структурой и титульным листом — в документе
  указываются только тип, тема и то, что отличается;
- поля, шрифт и интервалы по ГОСТ, содержание, нумерация страниц, разделы с новой страницы;
- вставные листы с автозаполнением форм — титульный, задание, отзыв, любые свои DOCX-шаблоны —
  после титульного листа, перед любым разделом, в конце или прямо в тексте;
- проверка состава разделов и заполнения полей;
- таблицы Markdown и HTML, сквозная нумерация, повтор шапки и подписи «Продолжение таблицы N»;
- рисунки и схемы draw.io (экспорт прямо при сборке), альбомные листы для широких схем;
- формулы LaTeX → редактируемые формулы Word с нумерацией; блоки кода, списки, курсив.

## Установка

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

Дополнительные программы — только для отдельных возможностей:

| Программа | Для чего | Где искать |
|---|---|---|
| [Pandoc](https://pandoc.org/installing.html) | формулы `$$ … $$` | в `PATH` |
| [draw.io Desktop](https://www.drawio.com/) | схемы `*.drawio` | `C:\Program Files\draw.io` или переменная `DRAWIO_PATH` |
| Microsoft Word | доводка: номера страниц в содержании, «Продолжение таблицы N», PDF | Windows |

## Быстрый старт

1. Один раз впишите свои данные — вуз, кафедру, ФИО, группу — в `marktogost.yaml` в корне
   проекта (образец — [examples/marktogost.yaml](examples/marktogost.yaml)).

2. Создайте заготовку документа нужного типа:

   ```bash
   python -m MarkToGost.main --types                    # список типов
   python -m MarkToGost.main --new курсовая моя.md      # → input/моя.md
   ```

3. Заполните шапку и пишите текст:

   ```markdown
   ---
   тип: курсовая
   дисциплина: Базы данных
   тема: Проектирование базы данных платформы 3D-печати
   руководитель: Петров П. П.
   ---

   # ВВЕДЕНИЕ

   Цель работы — …

   # 1 АНАЛИЗ ПРЕДМЕТНОЙ ОБЛАСТИ

   ## 1.1 Описание предметной области

   Таблица — Участники процесса
   | Роль | Задача |
   |---|---|
   | Заказчик | оформляет заказ |

   # ЗАКЛЮЧЕНИЕ

   # СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ
   ```

4. Соберите документ:

   ```bash
   python -m MarkToGost.main моя.md --pdf
   ```

   Результат — `output/моя.docx` и `output/моя.pdf` с титульным листом и содержанием.
   Флаг `--pdf` (или `--finalize` без PDF) доводит документ в Word; без Word собирается только DOCX.

Подробнее о типах, полях титульного листа и настройке под свой вуз —
[docs/document-types.md](docs/document-types.md); о разметке текста —
[docs/syntax.md](docs/syntax.md).

## Командная строка

```bash
python -m MarkToGost.main [файл.md] [--output файл.docx] [--finalize | --pdf] [параметры оформления]
python -m MarkToGost.main --new ТИП файл.md
python -m MarkToGost.main --types
```

- `файл.md` — путь или имя файла в `input/`; без него собираются все `.md` из `input/`.
- `--output`, `-o` — имя или путь результата, по умолчанию `output/<имя>.docx`.
- `--finalize` — доводка в Word: номера страниц в содержании, подписи «Продолжение таблицы N».
- `--pdf` — доводка и PDF рядом с DOCX.

Параметры оформления сильнее профиля и шапки документа; обычно они не нужны — те же значения
удобнее задать в шапке (см. [document-types.md](docs/document-types.md#параметры-оформления)).

| Параметр | Параметр шапки |
|---|---|
| `--font-name`, `--font-size`, `--line-spacing` | `шрифт`, `размер_шрифта`, `интервал` |
| `--first-line-indent`, `--use-first-line-indent` | `отступ_абзаца`, `красная_строка` |
| `--left-margin`, `--right-margin`, `--top-margin`, `--bottom-margin` | `поле_слева` … `поле_снизу` |
| `--image-width` | `ширина_рисунков` |
| `--caption-font-size`, `--caption-italic` | `размер_подписей`, `курсив_подписей` |
| `--table-font-size` | `размер_шрифта_таблиц` |
| `--code-font-size`, `--code-line-spacing` | `размер_шрифта_кода`, `интервал_кода` |

## Структура репозитория

```
MarkToGost/              пакет конвертера
├── main.py              командная строка и сборка документа
├── config.py            параметры оформления по умолчанию (документ без шапки)
├── structure.py         разделы, содержание и проверка структуры по профилю
├── formula_renderer.py  LaTeX → формулы Word через Pandoc
├── profiles/            типы документов (*.yaml) и шаблоны листов (titles/)
├── parser/              Markdown и шапка → список блоков
├── renderer/            блоки → DOCX, вставные листы
├── utils/               форматирование, оглавление, таблицы, draw.io
└── tests/               тесты pytest
docs/                    документация
prompts/                 промпты для нейросети по типам документов с журналом ошибок
examples/                примеры блоков и marktogost.yaml
tools/                   доводка в Word, сборка примеров и промптов, генератор шаблонов листов
input/, output/          ваши документы и результаты (не хранятся в git)
```

## Подготовка документов нейросетью

В папке [prompts/](prompts/) — системные промпты для нейросети по каждому типу документа:
как написать технически точный документ по ГОСТ и как подготовить его для MarkToGost. В каждом
промпте ведётся журнал ошибок оформления, который нейросеть пополняет сама.

```bash
python tools/prompt.py курсовая -o промпт.md     # общие правила + промпт курсовой
```
