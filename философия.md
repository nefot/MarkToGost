## Принцип разбивки

**Порядок важен** — каждый модуль импортирует только то, что ниже него:

```
config.py
    ↓
utils/  (не знают о parser/renderer)
    ↓
parser/  (знает о config, utils)
    ↓
renderer/  (знает о config, utils, parser, formula_renderer)
    ↓
main.py  (знает обо всём)
```

Никаких циклических импортов — `formula_renderer` не импортирует ничего из вашего проекта.

## С чего начать

Разбивайте по одному модулю за раз и сразу пишите тест:

**Шаг 1** — вынести `config.py`, запустить, убедиться что всё импортируется:
```python
# config.py
from config import DocumentSettings
assert DocumentSettings.FONT_SIZE_PT == 14
```

**Шаг 2** — вынести `utils/formatting.py`, написать `test_formatting.py`:
```python
def test_apply_italic_formatting_no_italic():
    result = apply_italic_formatting("обычный текст")
    assert result == [("обычный текст", False)]

def test_apply_italic_formatting_with_italic():
    result = apply_italic_formatting("до _курсив_ после")
    assert result == [("до ", False), ("курсив", True), (" после", False)]
```

**Шаг 3** — вынести `parser/blocks.py` + `parser/markdown_parser.py`, написать `test_parser.py`:
```python
def test_parse_formula_block():
    md = "$$\nF = ma\n$$\n\nгде $F$ — сила."
    blocks = MarkdownParser(md).parse()
    assert isinstance(blocks[0], FormulaBlock)
    assert blocks[0].latex == "F = ma"
    assert "где" in blocks[0].explanation
```

**Шаг 4** — renderer разбивается последним, когда parser уже покрыт тестами.
