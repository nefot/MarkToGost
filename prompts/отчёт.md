# Отчёт, пояснительная записка (тип `отчёт`)

Используется вместе с `00_общие_правила.md`.

## Что это за документ

Текстовый документ по ГОСТ 7.32-2017 без титульного листа: отчёт о научно-исследовательской
или лабораторной работе, пояснительная записка, техническое описание, инструкция, методические
указания. Содержание вставляется автоматически, каждый раздел — с новой страницы. Титульный
лист, если нужен, оформляется отдельно или подключается своим бланком:
`титульный_лист: титул.docx` (документ Word с полями `{{тема}}`, `{{студент}}` и т. п.).

## Шапка

```yaml
---
тип: отчёт
---
```

Других обязательных полей нет. Если подключён свой титульный лист или бланки, добавь их поля
в шапку. Если содержание не нужно (короткий отчёт на 3–5 страниц): `содержание: false`;
если разделы должны идти подряд без новых страниц: `разделы_с_новой_страницы: false`.

## Структура

Программа порядок разделов не проверяет — следуй ГОСТ 7.32-2017 и назначению документа.

Отчёт о НИР:

```markdown
# РЕФЕРАТ
# ВВЕДЕНИЕ
# 1 …
# ЗАКЛЮЧЕНИЕ
# СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ
# ПРИЛОЖЕНИЕ А. …
```

Отчёт о лабораторной работе:

```markdown
# 1 ЦЕЛЬ РАБОТЫ
# 2 ХОД РАБОТЫ
# 3 РЕЗУЛЬТАТЫ
# 4 ВЫВОДЫ
```

Инструкция или руководство: назначение и область применения, требования, подготовка, порядок
действий по шагам (нумерованный список, каждый шаг — одно действие), устранение неполадок.

**Схемы** (draw.io, раздел 4.8 общего промпта): схемы алгоритмов — по ГОСТ 19.701-90
(терминатор «Начало/Конец», процесс — прямоугольник, решение — ромб с выходами «Да»/«Нет»,
ввод-вывод — параллелограмм, поток сверху вниз и слева направо); схемы установок и устройств —
по ЕСКД (ГОСТ 2.701-2008); UML — по UML 2.5.

**Точность.** Результаты измерений — с единицами и погрешностью; расчёты — с формулами,
подставленными значениями и результатом; выводы — только из полученных данных.
