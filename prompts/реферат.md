# Реферат (тип `реферат`)

Используется вместе с `00_общие_правила.md`.

## Что это за документ

Реферат (доклад) по дисциплине — обзор и систематизация опубликованных сведений по теме
с выводами автора. Собственных исследований не требует, но требует корректного обращения
с источниками: всё, что взято из литературы, сопровождается ссылкой. Оформляется по
ГОСТ 7.32-2017 и требованиям преподавателя.

Обычный объём — 10–20 страниц. Источников — не меньше 8–10, из них большая часть — книги,
статьи, стандарты; сайты — только авторитетные (официальная документация, научные издания).

## Шапка

```yaml
---
тип: реферат
вуз: Полное название университета
факультет:
кафедра: Название кафедры
город: Город
дисциплина: Название дисциплины
тема: Тема реферата
студент: Фамилия И. О.
группа: Номер группы
руководитель: Фамилия И. О.
должность_руководителя: старший преподаватель
---
```

Обязательные поля: `вуз`, `кафедра`, `дисциплина`, `тема`, `студент`, `группа`,
`руководитель`, `город`. Для доклада: `вид_работы: ДОКЛАД`.

## Структура

```markdown
# ВВЕДЕНИЕ
# 1 <ПЕРВЫЙ АСПЕКТ ТЕМЫ>
## 1.1 …
# 2 <ВТОРОЙ АСПЕКТ ТЕМЫ>
# ЗАКЛЮЧЕНИЕ
# СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ
```

Программа проверяет: ВВЕДЕНИЕ → разделы с номером → ЗАКЛЮЧЕНИЕ → СПИСОК ИСПОЛЬЗОВАННЫХ
ИСТОЧНИКОВ.

**Введение** (около страницы): актуальность, цель, задачи, краткая характеристика основных
источников.

**Основная часть:** 2–4 раздела, логически раскрывающих тему; сравнение точек зрения разных
авторов со ссылками; таблицы и схемы, обобщающие материал. Не пересказ одного источника.

**Заключение:** выводы по каждой задаче, собственная позиция автора.

## Журнал ошибок и замечаний (реферат)

Правило ведения — как в разделе 8 общего промпта.

- **Симптом:** большие фрагменты текста без ссылок на источники.
  **Правило:** каждый факт, определение, цифра из литературы — со ссылкой `[N]`.
