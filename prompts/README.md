# Промпты для подготовки документов нейросетью

Промпты учат нейросеть писать документ, который MarkToGost соберёт правильно с первого раза:
технически точный, по ГОСТ и с корректной разметкой. Внутреннее устройство программы
в промптах не описывается — только стандарты и работа с программой.

| Файл | Назначение |
|---|---|
| `00_общие_правила.md` | работа с программой, разметка, стандарты, чек-лист, общий журнал ошибок |
| `курсовая.md` | курсовая работа или проект |
| `вкр.md` | выпускная квалификационная работа |
| `практика.md` | отчёт по практике |
| `реферат.md` | реферат, доклад |
| `отчёт.md` | отчёт о НИР или лабораторной работе, пояснительная записка без титульного листа |
| `договор.md` | договор, соглашение, акт |

## Как использовать

Соберите промпт — общие правила плюс тип документа — и передайте его нейросети как
системный промпт или первое сообщение:

```bash
python tools/prompt.py курсовая -o промпт.md
python tools/prompt.py --list
```

Затем дайте нейросети исходные материалы: тему, методичку, данные, код, требования
преподавателя.

## Журнал ошибок

В конце каждого промпта — журнал ошибок и замечаний. Нейросеть обязана дописывать в него
каждую новую ошибку оформления, замечание сборки или проверяющего в формате
«Симптом — Причина — Правило». Если у неё нет доступа к файлам, она выдаёт запись, и её
нужно вставить в соответствующий файл этой папки вручную. Общие ошибки — в
`00_общие_правила.md`, ошибки одного типа документа — в его файл.

Журнал — главный механизм улучшения: следующая модель получает все прошлые ошибки как
правила и не повторяет их.
