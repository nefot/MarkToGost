# TextBlock - Рендеринг текстовых блоков

Это простой текстовый блок. Он должен содержать обычный текст с поддержкой форматирования.

Текст может быть с _курсивом_, как показано выше. Курсив обозначается подчеркиванием: _текст_.

Вот ещё один абзац текста. Он должен быть выравнен по ширине (justify) и иметь отступ первой строки 1.25см.
