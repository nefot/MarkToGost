# ListBlock - Рендеринг списков

## Упорядоченный список

1. Первый элемент списка
2. Второй элемент с _курсивом_
3. Третий элемент
4. Четвёртый элемент

## Неупорядоченный список

– Первый пункт маркированного списка
– Второй пункт
– Третий пункт с _форматированием_
– Четвёртый пункт

Текст после списков должен быть на новой строке.
