# 📚 Примеры блоков MarkToGost

Этот каталог содержит примеры для каждого типа блока Markdown, поддерживаемого MarkToGost.

## 🎯 Структура

Каждый файл содержит **только один тип блока** и примеры его использования:

```
examples/blocks/
├── 01_TextBlock.md         # Текстовые абзацы, курсив
├── 02_HeadingBlock.md      # Заголовки 1-5 уровней
├── 03_ListBlock.md         # Упорядоченные и неупорядоченные списки
├── 04_CodeBlock.md         # Блоки кода (Python, JavaScript, etc)
├── 05_TableBlock.md        # Таблицы Markdown
├── 06_FormulaBlock.md      # Формулы LaTeX
├── 07_ImageBlock.md        # Изображения
└── 08_Section.md           # Секции (разделы)
```

---

## 📖 Описание каждого блока

### 1️⃣ TextBlock - Текстовые абзацы

**Файл:** `01_TextBlock.md`

**Синтаксис:**
```markdown
Это обычный текстовый абзац.

Второй абзац на новой строке.

Текст с _курсивом между подчёркиванием_.
```

**Проверяемые свойства:**
- ✅ Выравнивание по ширине (justify)
- ✅ Отступ первой строки (1.25см)
- ✅ Межстрочный интервал (1.5)
- ✅ Поддержка курсива (_текст_)

**Ожидаемый результат:**
- Текст печатается блоками
- Первая строка каждого абзаца имеет отступ
- Курсив отображается _именно так_

---

### 2️⃣ HeadingBlock - Заголовки

**Файл:** `02_HeadingBlock.md`

**Синтаксис:**
```markdown
# Заголовок 1-го уровня (title)

## Заголовок 2-го уровня

### Заголовок 3-го уровня

#### И так далее...
```

**Проверяемые свойства:**
- ✅ Уровень заголовка (1-9)
- ✅ Центрирование H1
- ✅ Выравнивание по левому краю остальных
- ✅ Жирность текста
- ✅ Отсутствие CAPS (заглушение капитализации)
- ✅ Поддержка курсива в заголовках

**Ожидаемый результат:**
- H1 центрирован, остальные слева
- Все заголовки жирные
- Большинство параметров Heading стиля работают

---

### 3️⃣ ListBlock - Списки

**Файл:** `03_ListBlock.md`

**Синтаксис:**
```markdown
## Упорядоченный список

1. Первый элемент
2. Второй элемент
3. Третий элемент

## Неупорядоченный список

– Первый пункт
– Второй пункт
– Третий пункт
```

**Проверяемые свойства:**
- ✅ Упорядоченные списки (с номерами)
- ✅ Неупорядоченные списки (маркеры "–")
- ✅ Первая строка с отступом (номер/маркер выносится влево)
- ✅ Поддержка курсива в элементах списка

**Ожидаемый результат:**
- Номера/маркеры выносятся слева
- Текст выравнен по ширине
- Курсив в элементах работает

---

### 4️⃣ CodeBlock - Блоки кода

**Файл:** `04_CodeBlock.md`

**Синтаксис:**
```markdown
```python
def hello():
    print("Hello")
```

```javascript
function hello() {
    console.log("Hello");
}
```
```

**Проверяемые свойства:**
- ✅ Определение языка программирования
- ✅ Форматирование отступов (специально для Python)
- ✅ Монопространственный шрифт (Courier New)
- ✅ Отступы слева и справа
- ✅ Сохранение форматирования

**Ожидаемый результат:**
- Код в окне с монопространственным шрифтом
- Правильные отступы и форматирование
- Инструкции Python имеют дополнительное форматирование

---

### 5️⃣ TableBlock - Таблицы

**Файл:** `05_TableBlock.md`

**Синтаксис:**
```markdown
| Столбец 1 | Столбец 2 | Столбец 3 |
| --- | --- | --- |
| Ячейка 1 | Ячейка 2 | Ячейка 3 |
| Ячейка 4 | Ячейка 5 | Ячейка 6 |
```

**Проверяемые свойства:**
- ✅ Правильное количество колонок
- ✅ Заголовок центрирован и жирный
- ✅ Данные слева, центрированы по вертикали
- ✅ Разбиение больших таблиц по страницам
- ✅ Повторение заголовка на каждой странице
- ✅ Подпись таблицы "Таблица N — Описание"
- ✅ Поддержка курсива в ячейках

**Ожидаемый результат:**
- Таблица на одной или нескольких страницах
- Заголовок повторяется если таблица большая
- Подбор ширины колонок под ширину текста

### 6️⃣ FormulaBlock - Формулы LaTeX

**Файл:** `06_FormulaBlock.md`

**Синтаксис:**
```markdown

**Проверяемые свойства:**
- ✅ Блочные формулы ($$...$$)
- ✅ Нумерация формул
- ✅ Встроенные формулы в тексте ($...$)
- ✅ Пояснения после формулы (где...)
- ✅ Сохранение LaTeX синтаксиса
- ✅ Преобразование в OMML (редактируемо в Word)

**Ожидаемый результат:**
- Формулы отредактируемы в Word
- Нумерация работает автоматически
- LaTeX команды преобразуются корректно

- Изображение центрировано

### 8️⃣ Section - Секции (разделы)

**Файл:** `08_Section.md`

**Синтаксис:**
```markdown
[//]: # (section=1 - Первый раздел)

Содержание раздела.

[//]: # (section=1.1 - Подраздел)

Содержание подраздела.
```

**Проверяемые свойства:**
- ✅ Начало новой страницы
- ✅ Нумерация разделов (1., 1.1, и т.д.)
- ✅ Вложенные разделы
- ✅ Разделы в оглавлении

**Ожидаемый результат:**
- Каждый раздел на новой странице
- Заголовок раздела вверху
- Оглавление собирается автоматически

## 🚀 Как использовать примеры

### Проверить один конкретный блок

```bash
# Обработать только TextBlock
python -m MarkToGost.main 01_TextBlock.md

# Результат в output/01_TextBlock.docx
```

### Проверить все блоки

```bash
# Скопировать все файлы в input/
cp examples/blocks/*.md input/

# Обработать все
python -m MarkToGost.main

# Каждый блок будет в output/
```

### Проверить конкретный файл вручную

1. Скопировать файл в `input/`
2. Запустить `python -m MarkToGost.main <имя_файла>`
3. Открыть результат в `output/`
4. Проверить каждое свойство

## 📝 Документация форматов

| Элемент | Синтаксис | Пример |
|---------|-----------|---------|
| Текст | Просто текст | `Это текст` |
| Курсив | `_текст_` | `_курсив_` |
| Заголовок | `# H1`, `## H2` | `# Заголовок` |
| Список упорядочен | `1.` | `1. Элемент` |
| Список неупорядочен | `– ` | `– Пункт` |
| Код | ` ```lang` | ` ```python` |
| Таблица | `\|` | `\| A \| B \|` |
| Формула блочная | `$$` | `$$E=mc^2$$` |
| Формула встроена | `$` | `$E=mc^2$` |
| Изображение | `![text](path)` | `![Fig](pic.png)` |
| Раздел | `[//]: # (section=)` | `[//]: # (section=1)` |
