# CodeBlock - Рендеринг блоков кода

## Пример на Python

```python
def hello_world():
    print("Hello, World!")
    return True

if __name__ == "__main__":
    hello_world()
```

## Пример на JavaScript

```javascript
function fibonacci(n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

Текст после блока кода продолжается нормально.
