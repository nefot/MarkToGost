# 📚 Полная спецификация MarkToGost

## 🎯 Что это?

**MarkToGost** - это конвертер Markdown → DOCX по стандарту ГОСТ 7.32-2001.

Проект должен быть **легко расширяемым** и содержать полную документацию.

## 🚀 Быстрый старт

### 1. Читать документ

```bash
# Понять архитектуру
cat ARCHITECTURE.md

# Начать разработку
cat EXTENDING_PARSER.md

# Найти ошибку
cat PARSER_DEBUGGING.md

# Написать тесты
cat TESTING.md
```

### 2. Тестировать

```bash
# Все юнит-тесты
pytest MarkToGost/tests/ -v

# Все блоки по отдельности
python test_blocks.py all

# Один конкретный блок
python test_blocks.py 01_TextBlock
```

### 3. Обработать файлы

```bash
# Все файлы из input/
python -m MarkToGost.main

# Один конкретный файл
python -m MarkToGost.main 01_TextBlock.md
```

## 📊 Структура при добавлении блока

Используйте этот порядок:

```
1. Определить @dataclass в parser/blocks.py
2. Добавить _is_<type>() и _parse_<type>() в parser/markdown_parser.py
3. Зарегистрировать в parse() методе
4. Создать renderer/<type>.py
5. Интегрировать в renderer/document_renderer.py
6. Создать тесты в tests/test_<type>.py
7. Добавить пример в examples/blocks/0N_<Type>.md
8. Обновить документацию
```
